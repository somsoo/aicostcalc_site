AI API 요금 계산기 소개

요청당 입력·출력 토큰과 하루 요청 수를 넣으면 요청 1회·하루·한 달·1년 요금을 어림하는 무료 도구입니다. 요청 1회 요금은 입력 토큰 ÷ 1,000,000 × 입력 가격 + 출력 토큰 ÷ 1,000,000 × 출력 가격으로 계산합니다.

기본 가격은 2026년 9월 30일에 OpenAI, Anthropic, Google의 공식 가격 페이지에서 확인한 표준 달러 가격입니다. 가격은 자주 바뀌므로 결과는 참고용 어림값으로만 써 주세요. 입력한 값은 브라우저 안에서만 계산하며 저장하거나 보내지 않습니다.
