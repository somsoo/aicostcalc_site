클로드(Claude) API 비용: 모델별 토큰 요금과 한 달 계산 예

확인일: 2026년 10월 30일 · 아래 출처의 법령과 공식 발표를 기준으로 작성했습니다.

  • 요금 = 입력 토큰 × 입력 가격 + 출력 토큰 × 출력 가격 (1M 토큰당 달러)
  • Opus 5.5 $4 / $20, Sonnet 5.5 $2 / $10, Haiku 5.5 $0.10 / $0.50 (입력 10만 토큰 이하)
  • 배치 API는 입력·출력 모두 50% 할인, 캐시에서 읽은 입력은 기본 가격의 10% 이하입니다.
  • Claude 4.7 이후 모델은 같은 글도 이전 모델보다 토큰이 약 30% 더 나옵니다.

모델별 표준 가격 (1M 토큰당 달러)

모델입력 / 출력예: 월 1만 회배치 사용 시
Claude Fable 5.1$10 / $50$450.00$225.00
Claude Opus 5.5$4 / $20$180.00$90.00
Claude Sonnet 5.5$2 / $10$90.00$45.00
Claude Haiku 5.5 (입력 10만 토큰 이하)$0.1 / $0.5$4.50$2.25
Claude Haiku 4.5 (이전 모델)$1 / $5$45.00$22.50

'월 1만 회'는 요청 1회에 입력 2,000토큰, 출력 500토큰을 쓴다고 가정한 계산입니다. Haiku 5.5는 요청 입력이 10만 토큰을 넘으면 $0.50 / $2.50입니다. 가격은 공급사가 자주 바꿉니다. 실제로 쓰기 전에 아래 공식 가격 페이지를 다시 확인하세요.

할인 받는 방법

  • 배치 API: 바로 답이 필요 없는 대량 작업을 묶어 보내면 입력·출력 모두 절반입니다.
  • 프롬프트 캐시: 같은 시스템 프롬프트나 문서를 반복해서 보낼 때 씁니다. 캐시에 쓰는 비용은 기본 입력의 1.25배(5분) 또는 2배(1시간)이고, 캐시에서 읽으면 기본 입력의 10%입니다(Opus 5.5·Sonnet 5.5는 5%, Fable 5.1은 2.5%).
  • 모델 나누기: 분류·추출 같은 단순 작업은 Haiku, 어려운 작업만 Opus로 보내면 비용이 크게 줄어듭니다.

비용이 예상보다 커지는 이유

  • 대화형 앱은 이전 대화를 매번 다시 입력으로 보내므로 대화가 길어질수록 입력 토큰이 늘어납니다.
  • 도구(tool)를 쓰면 요청마다 수백 토큰의 시스템 프롬프트가 추가됩니다.
  • 웹 검색 같은 서버 도구는 토큰과 별도로 사용량 요금이 붙습니다.

자주 묻는 질문

한국어는 토큰이 더 많이 나오나요?

영어보다 같은 내용에 토큰이 더 많이 나오는 편입니다. 계산기의 '글로 토큰 어림하기'로 대략 확인하고, 정확한 값은 API의 토큰 세기 기능으로 확인하세요.

Claude Pro 구독과 API 요금은 같나요?

다릅니다. 구독은 claude.ai 사용료이고, API는 쓴 토큰만큼 따로 청구됩니다.

원화로는 얼마인가요?

달러로 청구되므로 카드사 환율과 해외 결제 수수료에 따라 달라집니다. 계산기에 환율을 넣으면 원화로 볼 수 있습니다.
