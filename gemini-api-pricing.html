제미나이(Gemini) API 요금: 모델별 가격과 2027년 인상

확인일: 2026년 10월 30일 · 아래 출처의 법령과 공식 발표를 기준으로 작성했습니다.

  • Gemini 3.8 Flash 입력 $0.75는 2026년 12월 31일까지, 2027년 1월 1일부터 $1.50입니다.
  • Gemini 3.1 Pro Preview는 프롬프트가 20만 토큰을 넘으면 입력 $4, 출력 $18입니다.
  • Flash·Flash-Lite 계열은 무료 등급이 있지만 사용량 제한이 있고, 무료 등급 데이터는 제품 개선에 쓰일 수 있습니다.
  • 배치 API는 입력·출력 50% 할인입니다.

모델별 유료 등급 가격 (1M 토큰당 달러)

모델입력 / 출력예: 월 1만 회배치 사용 시
Gemini 3.1 Pro Preview (20만 토큰 이하)$2 / $12$100.00$50.00
Gemini 3.8 Flash (2026년 12월 31일까지)$0.75 / $3.75$33.75$16.88
Gemini 3.5 Flash-Lite$0.3 / $2.5$18.50$9.25
Gemini 2.5 Flash$0.3 / $2.5$18.50$9.25
Gemini 2.5 Flash-Lite$0.1 / $0.4$4.00$2.00

'월 1만 회'는 요청 1회에 입력 2,000토큰, 출력 500토큰을 쓴다고 가정한 계산입니다. 출력 가격에는 생각(thinking) 토큰이 포함됩니다. Gemini 3.8 Flash는 2027년 1월 1일부터 $1.50 / $7.50입니다. 가격은 공급사가 자주 바꿉니다. 실제로 쓰기 전에 아래 공식 가격 페이지를 다시 확인하세요.

2027년 인상에 대비하기

Gemini 3.8 Flash를 많이 쓴다면 2027년부터 같은 사용량의 요금이 두 배가 됩니다. 위 예시 기준 월 $33.75가 $67.50로 늘어납니다. 단순 작업은 Flash-Lite로 옮기고, 반복되는 프롬프트는 캐시를 쓰는 방법을 검토하세요.

무료 등급과 유료 등급

  • 무료 등급은 분당·하루 요청 수 제한이 있고, 무료 등급에서 보낸 내용은 Google이 제품 개선에 쓸 수 있다고 안내합니다.
  • 유료 등급은 제품 개선에 쓰지 않으며, 쓴 만큼 청구됩니다.
  • 3.1 Pro Preview는 무료 등급이 없습니다.

별도 요금이 붙는 기능

Google 검색 그라운딩은 무료 한도를 넘으면 검색 요청 수에 따라 따로 청구됩니다. 이미지·음성 출력도 토큰 가격이 다릅니다.

자주 묻는 질문

Gemini 앱(구독)과 API 요금은 같나요?

다릅니다. Google AI 구독은 Gemini 앱 사용료이고, API는 Google AI Studio·Cloud에서 쓴 만큼 따로 청구됩니다.

한국어 토큰은 어떻게 세나요?

모델의 토크나이저에 따라 다릅니다. 정확한 값은 API의 토큰 세기 기능으로 확인하세요.

가격이 바뀌면 계산기에 반영되나요?

공식 페이지를 다시 확인할 때 반영합니다. 계산기 상단에 확인한 날짜가 나옵니다.
