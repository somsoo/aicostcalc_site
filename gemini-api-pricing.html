제미나이(Gemini) API 요금: 모델별 가격과 2027년 인상

확인일: 2026년 11월 1일 · 아래 출처의 공식 가격 페이지를 기준으로 작성했습니다. 홈서버가 매주 공식 가격 페이지를 다시 읽고, 바뀐 가격이 이틀에 걸쳐 같게 확인되면 계산기와 안내 페이지에 자동으로 반영합니다.

  • Google 안내에 따르면 Gemini 3.8 Flash 입력 가격은 2026년 12월 31일까지 $0.75, 2027년 1월 1일부터 $1.50입니다.
  • Gemini 3.1 Pro Preview는 프롬프트가 200,000토큰을 넘으면 입력 $4, 출력 $18입니다.
  • Flash·Flash-Lite 계열은 무료 등급이 있지만 사용량 제한이 있고, 무료 등급 데이터는 제품 개선에 쓰일 수 있습니다.
  • 배치 API는 입력·출력 50% 할인입니다.

2027년 인상에 대비하기

Gemini 3.8 Flash를 많이 쓴다면 2027년 1월 1일부터 같은 사용량의 요금이 늘어납니다. 위 예시 기준 월 $33.75가 $67.50가 됩니다. 단순 작업은 Flash-Lite로 옮기고, 반복되는 프롬프트는 캐시를 쓰는 방법을 검토하세요.

무료 등급과 유료 등급

  • 무료 등급은 분당·하루 요청 수 제한이 있고, 무료 등급에서 보낸 내용은 Google이 제품 개선에 쓸 수 있다고 안내합니다.
  • 유료 등급은 제품 개선에 쓰지 않으며, 쓴 만큼 청구됩니다.
  • 3.1 Pro Preview는 무료 등급이 없습니다.

별도 요금이 붙는 기능

Google 검색 그라운딩은 무료 한도를 넘으면 검색 요청 수에 따라 따로 청구됩니다. 이미지·음성 출력도 토큰 가격이 다릅니다.

자주 묻는 질문

Gemini 앱(구독)과 API 요금은 같나요?

다릅니다. Google AI 구독은 Gemini 앱 사용료이고, API는 Google AI Studio·Cloud에서 쓴 만큼 따로 청구됩니다.

한국어 토큰은 어떻게 세나요?

모델의 토크나이저에 따라 다릅니다. 정확한 값은 API의 토큰 세기 기능으로 확인하세요.

가격이 바뀌면 계산기에 반영되나요?

홈서버가 매주 공식 가격 페이지를 다시 읽고, 바뀐 가격이 이틀에 걸쳐 같게 확인되면 계산기와 안내 페이지에 자동으로 반영합니다. 계산기 상단과 이 페이지의 확인일이 마지막으로 확인한 날짜입니다.
