어떤 작업에 적합한가요?

실시간 응답이 필요 없는 "백오피스" 또는 "대량 데이터 처리" 업무에 완벽합니다.

  • ✅ 수만 건의 고객 리뷰 감성 분석 (긍정/부정)
  • ✅ 상품 카탈로그 설명글 일괄 생성
  • ✅ 긴 문서나 과거 뉴스 기사 대량 요약
  • ✅ 대규모 DB 텍스트 번역 및 정제
  • ❌ 사용자 상담 챗봇 (실시간 응답 불가)

💡 자주 묻는 질문

Q. 결과는 무조건 24시간을 꽉 채워서 기다려야 하나요?

아닙니다. 최대 한도(SLA)를 24시간으로 보장할 뿐, AI 회사의 서버 리소스가 남는 상황이라면 몇 분에서 몇 시간 내에 처리가 완료되는 경우도 흔합니다.

Q. 한 번의 배치로 보낼 수 있는 용량 제한이 있나요?

OpenAI의 경우 파일당 최대 50,000건의 요청, 최대 파일 크기 100MB의 제한이 있습니다. 더 많은 작업을 하려면 파일을 여러 개로 쪼개서 보내면 됩니다.
