💡 자주 묻는 질문

Q. Claude 3.5 Sonnet API 요금은 얼마인가요?

2025년 기준 Claude 3.5 Sonnet은 입력 $3.00/1M 토큰, 출력 $15.00/1M 토큰입니다. 200K 토큰의 대용량 컨텍스트 윈도우가 강점으로, 방대한 문서 분석이나 긴 코드베이스 처리에 특히 유리합니다.

Q. Claude Haiku는 얼마나 저렴한가요?

Claude 3.5 Haiku는 입력 $0.80/1M, 출력 $4.00/1M으로 Sonnet 대비 약 4배 저렴합니다. 빠른 응답이 필요한 챗봇이나 대량 처리 작업에 적합하며, Claude 3 Haiku($0.25/1M)는 더욱 저렴하지만 성능이 낮습니다.

Q. Claude의 프롬프트 캐싱은 어떻게 작동하나요?

OpenAI와 달리 명시적으로 cache_control을 설정해야 합니다. 캐시 쓰기 비용(Sonnet $3.75/1M)이 발생하지만 캐시 읽기는 $0.30/1M으로 90% 저렴합니다. 최소 2,048 토큰 이상의 반복되는 시스템 프롬프트에 효과적입니다.
