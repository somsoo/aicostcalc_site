💡 자주 묻는 질문

Q. GPT-4o API 요금은 얼마인가요?

최신 기준 GPT-4o는 입력 $2.50/1M 토큰, 출력 $10.00/1M 토큰입니다. GPT-4o mini는 입력 $0.15/1M, 출력 $0.60/1M으로 훨씬 저렴합니다. 1M 토큰은 한국어 기준 약 150만~200만 글자에 해당합니다.

Q. GPT-4o와 GPT-4o mini 중 무엇을 선택해야 하나요?

단순 고객응대, FAQ 처리, 간단한 분류 작업은 GPT-4o mini가 17배 저렴해 압도적으로 유리합니다. 복잡한 추론, 코드 생성, 법률·의료 문서 분석은 GPT-4o를 권장합니다. 두 모델을 A/B 테스트해보고 품질 차이가 없다면 mini로 전환하세요.

Q. OpenAI 배치 API는 얼마나 저렴한가요?

배치 API를 사용하면 정가 대비 50% 할인됩니다. GPT-4o 배치는 입력 $1.25/1M, GPT-4o mini 배치는 입력 $0.075/1M입니다. 24시간 내 처리가 허용되는 대량 작업(문서 분류, 데이터 정제 등)에 최적입니다.
