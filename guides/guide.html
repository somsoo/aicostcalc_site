AI API 요금 어림하기 전에 알아 둘 것

AI API 요금은 쓴 토큰 수로 정해집니다. 계산기에 숫자를 넣기 전에 아래 다섯 가지를 확인하면 어림값이 실제 청구액에 더 가까워집니다.

1. 요금 공식

요청 1회 요금 = 입력 토큰 ÷ 1,000,000 × 입력 가격 + 출력 토큰 ÷ 1,000,000 × 출력 가격

예를 들어 입력 1,000토큰, 출력 500토큰을 1M 토큰당 입력 $2, 출력 $10인 모델로 보내면 $0.002 + $0.005 = $0.007입니다. 하루 100번이면 $0.70, 30일이면 $21.00입니다. 출력 가격이 입력보다 몇 배 비싼 모델이 많아서, 답변 길이를 줄이는 것이 요금에 크게 작용합니다.

2. 토큰 수는 직접 재 보기

영어는 대략 4글자 또는 0.75단어가 1토큰이라는 어림 규칙이 있습니다(Anthropic 가격 안내 FAQ). 한국어는 모델의 토크나이저마다 차이가 커서 글자 수만으로 어림하기 어렵습니다. 실제로 보낼 프롬프트와 답변 예시 몇 개를 공급사가 제공하는 토큰 세기 기능으로 재서 평균을 넣는 것이 가장 정확합니다. 같은 공급사 안에서도 모델이 바뀌면 토큰 수가 달라질 수 있습니다. Anthropic은 Claude 4.7 이후 모델이 같은 글에서 약 30% 더 많은 토큰을 만든다고 안내합니다.

3. 기다려도 되는 작업은 배치로

OpenAI, Anthropic, Google 모두 바로 답이 필요 없는 요청을 모아 보내는 배치 API를 입력·출력 50% 할인 가격으로 안내합니다. 밤새 문서를 요약하거나 대량 분류처럼 결과를 기다려도 되는 일에 맞습니다.

4. 아주 긴 프롬프트는 가격이 다를 수 있음

일부 모델은 요청 1회의 입력이 기준보다 길면 더 높은 가격을 받습니다. 2026년 9월 30일 확인 기준으로 GPT-6 계열은 입력 272,000토큰 초과, Gemini 3.1 Pro Preview는 프롬프트 200,000토큰 초과부터입니다. 긴 문서를 통째로 넣는다면 이 기준을 넘는지 먼저 보세요.

5. 계산에 들어가지 않는 비용

  • 프롬프트 캐싱 할인, 웹 검색 같은 도구 요금, 이미지·오디오 토큰
  • 지역·데이터 보관 위치에 따른 추가 요금, 별도 계약 할인, 세금
  • 달러 결제 시 카드사 환율과 해외 결제 수수료

가격은 예고와 함께 바뀌기도 합니다. Google은 Gemini 3.8 Flash 가격이 2027년 1월 1일부터 오른다고 안내하고 있습니다. 예산을 정하기 전에 공급사의 현재 가격 페이지를 다시 확인하세요.
