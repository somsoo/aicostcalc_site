🔤 AI 토큰(Token)이란? 한국어 포함 완벽 가이드

토큰이란 무엇인가?

토큰(Token)은 GPT, Claude, Gemini 같은 AI 언어 모델이 텍스트를 처리하는 가장 기본적인 단위입니다. 단어, 단어의 일부, 구두점 등으로 분리되며 AI API 요금은 바로 이 토큰 수를 기준으로 계산됩니다.

💡 핵심 공식: AI API 비용 = (입력 토큰 수 × 입력 단가) + (출력 토큰 수 × 출력 단가)

언어별 토큰 환산 기준

같은 의미라도 언어에 따라 토큰 수가 크게 달라집니다. 한국어는 영어보다 토큰을 더 많이 사용합니다.

언어평균 글자수/토큰예시토큰수
영어약 4글자"Hello there"~3토큰
한국어약 1.5~2글자"안녕하세요"~4~5토큰
중국어약 1.5글자"你好世界"~4~5토큰
숫자/기호약 1글자"12345"~5토큰

실전 토큰 계산 예시

텍스트한국어 글자수예상 토큰수
"안녕하세요, 오늘 날씨가 좋네요."16자~12~16토큰
일반 블로그 포스트 (600자)600자~400~500토큰
GPT-3.5 기본 대화 1회—~300~1,000토큰

소설 한 챕터 (약 5,000자)5,000자~3,500~4,500토큰

입력 토큰 vs 출력 토큰

AI API는 입력(Input)과 출력(Output) 토큰을 각각 다른 단가로 청구합니다. 출력 토큰이 항상 더 비쌉니다.

  • 입력(Input) 토큰: 내가 AI에 보내는 텍스트 (질문 + 시스템 프롬프트 + 대화 기록)
  • 출력(Output) 토큰: AI가 생성하는 응답 텍스트
  • 출력 단가가 입력 단가의 2~5배 높음 (GPT-4o 기준 4배)
  • 시스템 프롬프트도 입력 토큰에 포함됨 — 매 요청마다 소비
⚠️ 주의: 대화 히스토리를 전부 전달하면 입력 토큰이 누적됩니다. 긴 대화일수록 비용이 기하급수적으로 증가할 수 있습니다.

컨텍스트 윈도우(Context Window)란?

한 번의 API 요청에서 처리할 수 있는 최대 토큰 수입니다. 이 범위를 초과하면 앞부분 대화가 잘립니다.

모델컨텍스트 윈도우대략적 분량
GPT-4o128,000 토큰소설 약 200페이지
Claude 3.5 Sonnet200,000 토큰소설 약 300페이지
Gemini 2.5 Pro1,000,000 토큰소설 약 1,500페이지
GPT-4o mini128,000 토큰소설 약 200페이지

토큰 수를 줄이는 실전 팁

  • 시스템 프롬프트를 최대한 간결하게 작성하기
  • 불필요한 예의 표현 제거 ("~해 주세요" 대신 명령형)
  • 이미 알고 있는 컨텍스트 반복 금지
  • JSON 형식으로 구조화된 응답 요청 → 불필요한 말 줄이기
  • max_tokens 파라미터로 출력 길이 제한

💡 자주 묻는 질문 (FAQ)

Q. AI 토큰 1개는 몇 글자인가요?

언어마다 다릅니다. 영어는 약 4글자당 1토큰, 한국어는 약 1~2글자당 1토큰입니다. '안녕하세요'는 약 4~5토큰, 'Hello there'는 약 3토큰입니다. OpenAI의 Tokenizer 도구에서 직접 확인할 수 있습니다.

Q. 입력 토큰과 출력 토큰의 차이는 무엇인가요?

입력(Input) 토큰은 내가 AI에 보내는 질문+시스템 프롬프트의 토큰 수이고, 출력(Output) 토큰은 AI가 생성하는 응답의 토큰 수입니다. 출력 토큰이 입력 토큰보다 2~5배 비쌉니다. 비용 절감을 위해서는 응답 길이를 제한하는 것이 효과적입니다.

Q. 컨텍스트 윈도우란 무엇인가요?

한 번의 API 요청에서 처리할 수 있는 최대 토큰 수입니다. GPT-4o는 128K, Claude 3.5 Sonnet은 200K, Gemini 2.5 Pro는 무려 1M(100만) 토큰의 컨텍스트 윈도우를 지원합니다. 이 한도를 초과하면 오래된 대화 내용이 잘립니다.
